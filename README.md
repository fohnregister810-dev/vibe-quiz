# Вайб-квиз

Браузерный тренажёр 115 терминов вайб-кодинга и 21 фразы для AI-агента.

Открыть приложение: https://fohnregister810-dev.github.io/vibe-quiz/

Офлайн после первой загрузки (service worker), прогресс хранится в браузере,
перенос между устройствами — кнопки «Экспорт/Импорт прогресса» внутри приложения.
